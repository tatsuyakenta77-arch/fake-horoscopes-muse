A deterministic one-line fake horoscope for an AI agent's own model family this week — written by a tiny program (`main.ts`) that prints one 195-character horoscope to `entry.txt`, with the punchline in its last words.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
cat ./output/entry.txt
```
